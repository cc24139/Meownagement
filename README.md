
# Meownagement

Projeto para Controle de finanças com recompensas 


## Funcionalidades

- Anotar gastos e receitas do dia
- Anotar gastos recorrentes
- Criar metas de gasto
- Criar metas de economias
- Manter distribuição de renda
- Manter perfil e usuário
- Gerar resumos de gastos
- Resgatar pontos como recompensas
- Resgatar mascotes com pontos



## Stack utilizada

**Front-end:** Flutter    ![My Skills](https://skillicons.dev/icons?i=flutter)

**Back-end:** C# Minimal  ![My Skills](https://skillicons.dev/icons?i=cs)

**Data-Base**: SqlServer (Microsoft Management Studio)  ![My Skills](https://skillicons.dev/icons?i=mysql)
